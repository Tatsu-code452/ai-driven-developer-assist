# 1. システム概要

本システムは、AIを活用したソフトウェア開発支援システムである。

要件分析からプロジェクト計画、設計、実装、テスト、課題管理、QA管理、トレーサビリティ管理、およびGit/GitHubによる構成管理までを一元的に管理する。 【1-a22377】【2-6d9f88】
