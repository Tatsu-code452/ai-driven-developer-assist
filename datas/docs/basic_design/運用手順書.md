# 4. プロジェクト管理

## 4.1 プロジェクト登録

### 手順

1. システムを起動する
2. プロジェクト一覧を表示する
3. プロジェクト追加を選択する
4. 以下を入力する

| 項目                     | 内容                   |
| ------------------------ | ---------------------- |
| プロジェクト名           | 対象案件名             |
| 説明                     | 案件概要               |
| 状態                     | 計画中 / 進行中 / 完了 |
| 管理データパス(rootPath) | プロジェクト保管先     |

5. 登録する

### 成果物

- プロジェクト情報
- 管理データルート

---

## 4.2 プロジェクト選択

### 手順

1. プロジェクト一覧を表示
2. 対象プロジェクトを選択
3. 作業コンテキストを確立

### 結果

以後の作業は選択中プロジェクト配下で実施する。

# 17. 運用ルール

## AI利用時

AIが生成した成果物は必ずレビューを実施する。

## 登録ルール

生成成果物は必ずドキュメントまたは管理データとして登録する。

## トレーサビリティ

要件から成果物までの追跡情報を維持する。

## Git管理

すべてのソース変更はGit管理下で実施する。
