# 4. Frontend構築

## frontend移動

```bash
cd frontend
```

---

## Vite + React + TypeScript 作成

```bash
npm create vite@latest . \
  -- \
  --template react-ts
```

---

## 依存ライブラリ導入

### React Router

```bash
npm install react-router-dom
```

### Axios

```bash
npm install axios
```

### Astryx

```bash
npm install @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex
npm install -D @astryxdesign/cli
```

---

## Tailwind CSS導入

```bash
npm install -D tailwindcss @tailwindcss/vite
```

---

### vite.config.ts

```ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),
  ],
});
```

---

### src/index.css

```css
@import "tailwindcss";
```

# 6. Vitest構築

導入

```bash

```

```bash

```


```bash

```

---

## vite.config.ts

```ts

    environment: "jsdom",
}
```

---

## テスト実行

```bash

```

---

# 7. Coverage設定

導入

```bash
npm install -D @vitest/coverage-v8@$(npm pkg get devDependencies.vitest)
```

---

## vite.config.ts

```ts
test: {
    coverage: {
        reporter: [
            "text",
            "html"
        ]
    }
}
```

---

## Coverage実行

```bash
npm run test -- --coverage
```

---

# 8. Frontend package.json

scripts追加

```json
{
  "scripts": {
    "dev": "vite",
    "build": "tsc && vite build",
    "preview": "vite preview",
    "lint": "eslint src",
    "test": "vitest",
    "coverage": "vitest run --coverage"
  }
}
```
