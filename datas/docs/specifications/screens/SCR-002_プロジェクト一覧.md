## 1. 概要

システム利用者が管理対象プロジェクトを検索・選択・作成するための画面。

運用フローにおけるプロジェクト選択および作業コンテキスト確立の入口画面となる。

---

## 2. 目的

- 開発対象Projectの検索
- Project選択
- Current Project設定
- Project作成
- Project状態確認
- 作業コンテキスト確立

---

## 4. 業務ルール

### BR-001

作業開始前にProject選択を行う。

---

### BR-002

同時選択可能なProjectは1件のみ。

---

### BR-003

Project選択後はCurrent Projectとして保持する。

---

### BR-004

Current Projectは以下画面の検索条件として利用する。

- Context
- WorkItem
- Prompt
- AIExecution
- Artifact
- QA
- 課題

---

### BR-005

一覧表示対象は論理削除されていないProjectのみとする。

---

## 6. 入力項目

| 項目       | 必須 | 説明       |
| ---------- | ---- | ---------- |
| 名称検索   |      | 部分一致   |
| 状態       |      | 状態絞込   |
| 作成日From |      | 作成開始日 |
| 作成日To   |      | 作成終了日 |

---

## 7. 表示項目

| 項目       | 説明        |
| ---------- | ----------- |
| Project ID | 識別子      |
| 名称       | Project名称 |
| 状態       | Project状態 |
| rootPath   | 管理パス    |
| 成果物件数 | Artifact数  |
| 作業件数   | WorkItem数  |
| 更新日時   | 更新日時    |

---

## 8. 操作

| ---------- | ------------------- |
