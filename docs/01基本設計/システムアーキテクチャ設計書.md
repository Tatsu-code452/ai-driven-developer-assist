# システムアーキテクチャ設計書（ドラフト）

## 1. アーキテクチャ概要

本システムは以下の5レイヤで構成する。

### Presentation Layer

利用者向けUI

対象

- ダッシュボード
- プロジェクト管理画面
- コンテキスト管理画面
- 成果物管理画面

---

### Application Layer

業務ロジック

対象

- コンテキスト管理
- プロンプト管理
- ドキュメント管理
- トレーサビリティ管理
- プロジェクト管理

---

### AI Support Layer

AI利用支援機能

対象

- AI入力生成
- Markdown整形
- PDF変換
- Office変換
- OCR
- 成果物整形

---

### Repository Layer

データアクセス層

対象

- Markdown
- JSON
- 設定ファイル

---

### External Layer

外部サービス

対象

- Git
- GitHub
- Backlog
- Copilot
- GitHub Copilot
- Gemini

---

## 2. アーキテクチャ原則

### AR-001

1機能1責務とする。

### AR-002

成果物はMarkdownで保持する。

### AR-003

成果物のバージョンはGitに委譲する。

### AR-004

AI差異を吸収する層を持つ。

### AR-005

すべてのAI利用はコンテキスト管理機能を経由する。
