# 3. フロントエンド

用途

- SPA構築
- 画面管理
- UIコンポーネント

採用理由

- エコシステムが豊富
- TypeScriptとの相性が良い
- 長期運用に向く

用途

- 型定義
- DTO定義
- API契約

採用理由

- 型安全性
- 開発効率向上
