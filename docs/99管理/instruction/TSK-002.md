# TSK-002 識別子・命名方針のQA確認

- Phase: Phase 0 / QA・採番方針
- 依存: なし
- 計画: 4時間、2026-11-05（計画日）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。開始時に作業環境と既存状態を確認し、関連資料の事実だけで作業する。

QA記録に次の未決事項を整理する: 要件定義書のQA PREFIX「QA」とデータモデル設計書の「QAA」の不一致、ID重複禁止の適用範囲（全成果物間か同一種別内か）、TSK-001で付与された暫定IDを確定IDとして扱えるか。権限のある関係者の回答・承認を得る前に、いずれかの案を正として決めない。既存のQA記録があれば追記・更新し、重複票を作らない。回答・承認が未取得なら、確認依頼と必要な判断事項を記録し、未解決として報告する。

### 完了条件

- QA記録に3つの論点と回答・承認の根拠が残っている。
- 回答がない論点は未決として明示し、暫定IDを確定扱いしない。
