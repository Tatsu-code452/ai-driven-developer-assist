# TSK-004 Node.js/npm・GitHub・CI環境の整備

- Phase: Phase 0 / 開発環境
- 依存: なし
- 計画: 32時間、2026-11-16〜2026-11-25（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。既存の技術選定・環境構築手順・リポジトリ設定を確認し、プロジェクトでNode.js/npmを利用できる状態とCI利用可能な状態を整える。

GitHub上での作成・設定など外部操作は、既存権限と明示された許可の範囲に限る。権限や必要な値が不足している場合、認証情報を要求・表示・保存せず、ローカルで可能な作業とブロッカーを報告する。依存追加は必要最小限にし、npm安全運用標準が未整備なら安全側の既存パターンに従う。

### 完了条件

- 対象プロジェクトでNode.js/npmを使える。
- GitHubリポジトリとCIが利用可能であることを、設定と実行結果で確認する。権限等で実確認できない場合は、未確認として明示する。
