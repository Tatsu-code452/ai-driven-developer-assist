# TSK-005 管理基盤の画面遷移・優先画面設計

- Phase: Phase 1 / 画面設計
- 依存: なし
- 計画: 24時間、2026-11-26〜2026-12-03（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。画面遷移図を作成または更新し、一覧・詳細・遷移の関係をレビュー可能な形で示す。

### 対象範囲

- SCR-002、003、021、022、024、007、008の一覧・詳細・遷移
- 推奨次タスクとしてSCR-005、013、014も設計対象とする

既存の画面一覧、要件、方針との整合をとり、画面IDや仕様を新たに捏造しない。

### 完了条件

- 画面遷移図から上記画面の一覧・詳細・画面間遷移を確認できる。
- 未決の画面挙動は未決として記載されている。
