# TSK-008 QA・課題管理

- Phase: Phase 1 / QA・課題管理（MVP Step1）
- 依存: TSK-005、TSK-002
- 計画: 40時間、2027-01-19〜2027-02-01（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-005とTSK-002が完了済みか[WBS-001](../WBS-001.md)で確認する。未完了ならブロッカーとして報告し、特に識別子方針が未承認の場合はQAを確定IDで採番しない。

### 完了条件

- QAと課題をプロジェクトに関連付けて登録・参照できる。
- QA識別子はTSK-002の承認結果に従う。回答が未確定なら承認済みID発行を保留する。
- 課題・QAの項目や状態遷移を、根拠なく作らない。
