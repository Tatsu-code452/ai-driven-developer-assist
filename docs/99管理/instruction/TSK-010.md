# TSK-010 成果物識別子の採番機能

- Phase: Phase 1 / 採番管理（MVP Step1）
- 依存: TSK-009
- 計画: 24時間、2027-02-02〜2027-02-09（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。設計TSK-009の完了と採番方針の承認状況を確認し、その設計に従って識別子の発行と重複検出を実装する。依存が未完了、または採番規則が未承認なら、規則を推測して実装せずブロッカーを報告する。

### 完了条件

- 承認済み採番方針に基づいて識別子を発行できる。
- 方針で定めた範囲の重複を検出できる。
- 未承認のID範囲やPREFIX解釈を実装で固定していない。
