# TSK-013 成果物の登録・参照管理

- Phase: Phase 1 / 成果物管理（MVP Step1）
- 依存: TSK-012
- 計画: 40時間、2027-02-18〜2027-03-03（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。依存TSK-012の詳細設計を確認し、既存成果物を登録・参照できる機能を設計・実装する。依存設計が未完了ならブロッカーを報告し、未承認の仕様を推測で追加しない。

### 完了条件

- 成果物の識別情報、種別、パスを登録・参照できる。
- 現在作成済みの成果物を登録できる。
- パスや識別情報を扱う際に、既存のセキュリティ・入力検証規約を守る。
