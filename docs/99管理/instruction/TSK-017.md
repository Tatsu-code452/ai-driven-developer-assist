# TSK-017 プロジェクト雛形・ダッシュボード

- Phase: Phase 1 / 初期アプリケーション
- 依存: TSK-004
- 計画: 24時間、2026-12-04〜2026-12-11（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-004の完了を[WBS-001](../WBS-001.md)で確認し、プロジェクトの既存技術選定・構成に従ってアプリケーション雛形とダッシュボードを作成する。依存が未完了ならブロッカーを報告する。

### 完了条件

- アプリケーションを起動できる雛形がある。
- ダッシュボードを表示できる。
- 既存の画面設計・技術スタックと整合し、不要な依存や機能を追加していない。
