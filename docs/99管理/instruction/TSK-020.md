# TSK-020 AI入力パッケージ・SCR-013設計

- Phase: Phase 2 / AI入力設計（MVP Step4）
- 依存: なし
- 計画: 24時間、2027-05-11〜2027-05-18（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。AI入力パッケージおよびSCR-013の設計を作成または更新し、既存のコンテキスト・プロンプト管理設計と整合させる。

### 完了条件

- 入力対象情報、プロンプト反映、Markdown出力の仕様が設計されている。
- 人間が内容を確認してAIへ入力する運用を維持する。
- 情報の自動送信など、承認されていない挙動を追加しない。
