# TSK-021 AI入力生成

- Phase: Phase 2 / AI入力生成（MVP Step4）
- 依存: TSK-020
- 計画: 32時間、2027-05-19〜2027-05-28（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-020の承認済み設計を確認し、その仕様の範囲でコンテキスト情報の集約、プロンプト反映、AI投入用Markdown出力を実装する。依存設計が未完了ならブロッカーを報告する。

### 完了条件

- 設計された範囲の情報を集約できる。
- 保存済みプロンプトを反映したAI投入用Markdownを出力できる。
- 設計にないデータを暗黙に追加せず、利用者が確認できる形で出力する。
