# TSK-022 AI回答取込・成果物反映・差分表示

- Phase: Phase 2 / AI回答取込（MVP Step4）
- 依存: TSK-005
- 計画: 32時間、2027-05-31〜2027-06-09（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-005の完了を確認し、既存画面設計・要件に従って利用者がAI回答を取り込み、成果物への反映前後の差分を確認できる機能を実装する。依存が未完了ならブロッカーを報告する。

### 完了条件

- 利用者がAI回答を取り込める。
- 成果物へ反映する前後の差分を確認できる。
- 自動的なAI入出力や利用者の確認を伴わない上書きを行わない。
