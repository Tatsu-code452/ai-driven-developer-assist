# TSK-023 Markdown構文・リンク・フォーマット検証

- Phase: Phase 3 / Markdown検証
- 依存: なし
- 計画: 24時間、2027-06-10〜2027-06-17（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。既存のMarkdown・AI成果物標準と検証基盤を確認し、構文、リンク、フォーマットの検証を実装する。基準が未定義の場合は根拠なく厳格な基準を導入せず、要確認として報告する。

### 完了条件

- Markdown構文、リンク、フォーマットをそれぞれ検証できる。
- 利用者が各検証結果を確認できる。
- 正常・異常の代表例を用いて検証する。
