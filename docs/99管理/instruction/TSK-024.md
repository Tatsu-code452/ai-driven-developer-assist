# TSK-024 採番重複・未関連成果物の検出

- Phase: Phase 3 / トレーサビリティ検証
- 依存: TSK-010、TSK-011
- 計画: 24時間、2027-06-18〜2027-06-25（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-010とTSK-011の完了を[WBS-001](../WBS-001.md)で確認し、承認済み採番範囲における重複と関連付けのない成果物を検出する機能を実装する。依存または採番範囲が未確定なら推測せずブロッカーを報告する。

### 完了条件

- 承認済み採番範囲でID重複を検出できる。
- 関連付けのない成果物を検出できる。
- 検出結果が既存のマトリクス・管理データと整合する。
