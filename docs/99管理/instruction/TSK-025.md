# TSK-025 AI成果物標準・コピー可能性・品質検証

- Phase: Phase 3 / AI成果物検証
- 依存: なし
- 計画: 24時間、2027-06-28〜2027-07-05（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。承認済みのAI成果物標準と品質基準を調査し、それに基づく検証結果を提示する機能を実装する。追加承認や根拠が未確定の基準は固定せず、必要な判断とブロッカーを明示する。

### 完了条件

- 検証基準が承認済み範囲で明文化されている。
- その基準に基づくAI成果物標準・コピー可能性・品質の検証結果を提示できる。
- 未承認の基準を既定仕様として扱っていない。
