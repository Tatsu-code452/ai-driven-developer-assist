# TSK-026 PDF・Office・画像テキスト変換／OCR

- Phase: Phase 4 / ファイル変換
- 依存: なし
- 計画: 48時間、2027-07-06〜2027-07-21（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。既存の技術構成と要件を確認し、PDF、Word、Excel、PowerPoint、画像それぞれのテキスト変換・OCRを支援する機能を実装する。対応形式・制約を明記し、要件にないファイル処理範囲を拡張しない。

### 完了条件

- PDF、Word、Excel、PowerPoint、画像の対象ごとに入力と出力を確認できる。
- 実際に対応する形式・制約が利用者に分かる。
- 代表的な入力で結果を検証し、未対応や失敗を明示する。
