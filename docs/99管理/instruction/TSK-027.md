# TSK-027 Git状態・ブランチ・マージ・採番競合支援

- Phase: Phase 4 / Git支援
- 依存: TSK-010
- 計画: 40時間、2027-07-22〜2027-08-04（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-010の完了を確認し、Git運用標準と既存の安全規則に従ってGit状態・ブランチ確認、設計範囲内のマージ支援、採番競合検知を実装する。破壊的または不可逆なGit操作を自動実行しない。

### 完了条件

- Git状態とブランチを確認できる。
- 設計範囲のブランチ・マージ支援と採番競合検知を確認できる。
- マージなど状態を変更する操作は利用者が確認でき、既存のGit運用標準に従う。
