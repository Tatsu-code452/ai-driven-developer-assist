# TSK-028 関連成果物推薦・コンテキスト自動抽出

- Phase: Phase 5 / コンテキスト提案
- 依存: TSK-016
- 計画: 32時間、2027-08-05〜2027-08-16（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-016の完了を[WBS-001](../WBS-001.md)で確認し、承認済みのコンテキスト境界に沿って関連成果物候補とコンテキスト自動抽出を支援する。依存が未完了ならブロッカーを報告する。

### 完了条件

- 関連成果物の候補を提示し、利用者が確認できる。
- 自動抽出範囲は承認済みコンテキスト境界に従う。
- 利用者が確認・選択できない形で情報を自動送信しない。
