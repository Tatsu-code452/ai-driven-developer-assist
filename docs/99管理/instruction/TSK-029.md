# TSK-029 プロンプト／サブエージェント生成支援

- Phase: Phase 5 / プロンプト生成支援
- 依存: TSK-019
- 計画: 32時間、2027-08-17〜2027-08-26（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-019の完了を確認し、承認済み設計の範囲でプロンプトおよびサブエージェント生成を支援する機能を実装する。サブエージェントに関する未決事項を前提にしない。

### 完了条件

- 承認済み設計の範囲で生成結果を提示できる。
- 利用者が結果を確認できる。
- 未承認の設定・権限・自動実行を追加しない。
