# TSK-030 次工程・不足成果物・トレーサビリティ不足の提案

- Phase: Phase 5 / 作業提案
- 依存: TSK-011
- 計画: 32時間、2027-08-27〜2027-09-07（計画期間）

## AI実行プロンプト

Router Agentとして、このチケットだけを実行する。TSK-011の完了を[WBS-001](../WBS-001.md)で確認し、管理データとトレーサビリティ情報に基づいて次工程、不足成果物、関連不足を提案する機能を実装する。要件に直接対応する機能要件がないため、提案の根拠と利用者確認を必須とし、未承認のルールを作らない。

### 完了条件

- 次工程、不足成果物、関連不足の各提案を根拠とともに提示できる。
- 利用者が提案内容を確認できる。
- 根拠がないときは提案を捏造せず、判断できない旨を示す。
