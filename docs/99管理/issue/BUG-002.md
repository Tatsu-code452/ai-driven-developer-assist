# BUG-002 管理データが1ファイル1内容になっていない

[課題一覧に戻る](README.md)

## 内容

サブエージェントに関する管理データに、1ファイルへ複数の管理内容をまとめているものがある。1つの管理内容を単独で参照・更新・受け渡しできず、AIが不要な情報まで読む原因になる。

## 期待する状態

管理IDごとに内容を分離し、1ファイルを1管理内容とする。既存の管理記録との参照を保ちながら、適用範囲を確認して分割する。
