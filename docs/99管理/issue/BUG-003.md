# BUG-003 管理IDの状態参照先が分散・冗長

[課題一覧に戻る](README.md)

## 内容

管理IDの状態を確認するための参照先が増え、管理情報をたどる手間が生じている。状態が個別記録や複数の一覧に分散すると、更新漏れや不整合も起こりやすい。

## 期待する状態

READMEに管理IDと状態を集約し、個々の詳細はIDごとのファイルに記録する。管理IDから不要な中継資料をたどらずに詳細へ到達でき、状態の正本が一つであること。
