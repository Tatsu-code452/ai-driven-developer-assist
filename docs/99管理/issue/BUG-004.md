# BUG-004 AIに渡すコンテキストを最小化できていない

[課題一覧に戻る](README.md)

## 内容

サブエージェントが作業時に必要とする情報を絞り込む工夫が不足しており、不要な管理情報まで読み込む可能性がある。

## 期待する状態

担当作業と管理IDを起点に必要な資料だけを参照できる構造・手順にし、重複した説明や不要な参照を減らす。コンテキスト量や削減目標は未定義のため、根拠なく数値目標を設定しない。
