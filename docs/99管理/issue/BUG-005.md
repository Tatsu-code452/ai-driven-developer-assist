# BUG-005 ログに見られる反復作業をAIで代替できていない

[課題一覧に戻る](README.md)

## 内容

ログ1〜4に記録された作業を確認し、AIが繰り返し行っている作業のうち定型化・自動化できるものを特定して一部を代替する必要がある。候補作業はログの内容を分析してから決定し、現時点では特定の作業を自動化対象として断定しない。

## 期待する状態

ログから反復作業と手作業による確認箇所を抽出し、安全に自動化できる手順を選定する。自動化によりクレジット・トークン消費を抑えられるか、実施前後を比較できる形で検証する。
