# BUG-006 クレジット・トークン消費と処理速度の改善が不足

[課題一覧に戻る](README.md)

## 内容

AIを用いた作業におけるクレジット・トークン消費を抑え、処理速度を向上させる工夫が不足している。反復作業の自動化（[BUG-005](BUG-005.md)）以外も含め、改善可能な点を調査する必要がある。

## 期待する状態

コンテキスト量、作業手順、AI呼び出しなどの改善候補を確認し、実際の利用に基づき効果と副作用を検証する。目標値や測定条件は未定義のため、根拠なく設定しない。
