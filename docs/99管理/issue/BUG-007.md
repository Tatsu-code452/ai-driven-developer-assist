# BUG-007 トレーサビリティマトリックスの網羅性が不足

[課題一覧に戻る](README.md)

## 内容

現在のトレーサビリティマトリックスでは、管理対象間の依存関係を網羅的・明確に確認しにくい。管理ID単位で、どの管理情報がどの管理情報に依存しているかを示す必要がある。

## 期待する状態

要件IDを縦軸に置き、設計・テスト・運用など一通りの管理情報のIDを横軸に置く。依存関係のある交点に「〇」を記載し、1つの要件IDに複数の依存先がある場合もそれぞれ記録する。対象となる管理種別と依存関係の根拠を明確にし、関係のない箇所は依存ありと誤認されない表現にする。
