# BUG-008 仮版画面と不要な遷移により操作性が悪い

[課題一覧に戻る](README.md)

## 内容

アプリの画面レイアウトが仮版のため利用しにくく、不要な画面遷移もある。画面全体のUXも悪く、利用者が操作しにくい。

## 期待する状態

実際の利用者操作を踏まえて画面レイアウトと遷移を見直し、不要な遷移をなくして、迷わず操作できるUXにする。利用者の操作シナリオと確認方法は未定義のため、設計・実装時に明確にする。
