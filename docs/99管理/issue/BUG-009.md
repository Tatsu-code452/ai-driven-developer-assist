# BUG-009 アプリとAI作成管理情報の粒度が不整合

[課題一覧に戻る](README.md)

## 内容

AIで作成した管理情報とアプリで扱う管理情報の粒度が合っていない。依頼者が望む粒度はAIで作成した管理情報の粒度であり、現在のアプリはその管理情報を読み込んで扱う形になっていない。

## 期待する状態

アプリがAI作成済みの管理情報を読み込み、同じ管理単位・粒度で表示・管理できるようにする。対応する管理情報の形式、読込対象、更新の扱いは設計時に明確にする。
