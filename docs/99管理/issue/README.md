状態の意味:

- **未対応**: 登録済みで、対応を開始していない。
- **対応中**: 対応作業中。
- **解決済み**: 対応結果と根拠を個別課題ファイルに記録済み。
- **保留**: 対応を保留し、理由を個別課題ファイルに記録済み。

個別課題ファイルには状態を重複記載しない。変更時は本表の状態を更新し、必要な判断・対応根拠を個別課題に追記する。担当者・期限は根拠がないため設定しない。
