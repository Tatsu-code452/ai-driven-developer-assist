# 要件レジスター

- 登録形式: `REQ-001`〜`REQ-077`（各行が個別要件。文書自体に別IDは付与しない）
- 対象システム: AI駆動型開発支援システム
- 状態: 要件定義書に明記された事項を登録。未決事項・承認待ちは各項目および「未解決事項」に明記。
- 主な出典: [要件定義書](../../00要件/要件定義書.md)
- 関連資料: [要件](../../00要件/要件.md)、[データモデル設計書](../../01基本設計/データモデル設計書.md)、[ディレクトリ構成設計書](../../01基本設計/ディレクトリ構成設計書.md)

## 1. 範囲

要件定義書に明記された、AI駆動型開発支援システムの目的、機能要件、非機能要件を登録する。設計や実装方式は定めない。受入基準は原文の要求を観察可能な形にしたものであり、原文にない数値目標・閾値は設定しない。数値等が示されていない品質目標は、その旨を基準に記す。

## 2. アクター

- **利用者**: GUIを操作し、AIとの入出力を人手で行う者。AI利用経験が少ない利用者も想定される。
- **対象AIサービス**: Microsoft Copilot、GitHub Copilot、Gemini。無償版利用が前提。

管理者、権限区分等の別アクターは要件定義書に記載がないため追加しない。

## 3. ユースケース

以下は要件から読み取れる利用目的の整理であり、未記載の業務手順を規定するものではない。

1. 利用者が画面からシステムの機能を使う。
2. 利用者が関心事ごとのコンテキストを管理・再利用し、AIへの作業指示に利用する。
3. 利用者が役割・目的に応じたプロンプトおよび成果物テンプレートを利用する。
4. 利用者がプロジェクト情報、課題、QA、タスク、成果物およびそれらの関連を管理する。
5. 利用者がファイル変換、コマンド作業、AI入力整形、AI回答からの成果物作成を支援する機能を利用する。
6. 利用者がAIに入力を渡し、AI回答を受け取る。アプリケーションはAIとの直接入出力を行わない。
