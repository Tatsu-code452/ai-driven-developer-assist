# TRC-001 トレーサビリティマトリックス

## 1. 目的・読み方

本表は、[要件一覧・状態管理](../requirements/README.md)とIDごとの要件ファイルに登録された REQ-001〜REQ-077 を、要件定義書の出典節と対応づける。タスク欄はWBSに記載された計画上の対応であり、実装・完了・要件充足を示さない。QA欄は未回答QAへの関連、課題欄は課題記録が明示する関連を示す。空欄相当の「—」は、確認した資料に根拠のあるリンクがないことを示す。
