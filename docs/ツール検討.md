プロジェクト作成支援
今回はreact,typescript,tailwindcssを使用する前提でプロジェクトを作成する
bashで作成できるように
npm create vite@latest my-app -- --template react-ts
上記で作成したあとの依存を安全化してインストール

tailwindcssのインストール(typescriptの場合)
npm install -D tailwindcss postcss autoprefixer
型定義
npm install -D @types/tailwindcss
npm install -D @tailwindcss/vite

tailwindcssの初期化
npx tailwindcss init -p

tailwind.config.jsの編集
module.exports = {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}

tailwindcssのCSSをインポート
index.cssに以下を追加
@tailwind base;
@tailwind components;
@tailwind utilities;

tailwindcssを使用するために、index.tsxに以下を追加
import './index.css'

tsconfig.jsonの編集(tailwindcssの設定は不要)
{
  "compilerOptions": {
    "target": "esnext",
    "useDefineForClassFields": true,
    "lib": [
      "dom",
      "dom.iterable",
      "esnext"
    ],
    "allowJs": false,
    "skipLibCheck": true,
    "esModuleInterop": false,
    "allowSyntheticDefaultImports": true,
    "strict": true,
    "forceConsistentCasingInFileNames": true,
    "noFallthroughCasesInSwitch": true,
    "module": "esnext",
    "moduleResolution": "node",
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx"
  },
  "include": [
    "./src"
  ]
}

vite.config.tsの編集(tailwindcssの設定は不要)
import { defineConfig } from 'vite' 

import react from '@vitejs/plugin-react'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
  },
})

tailwindcssの設定が必要なファイルはtailwind.config.jsとindex.cssのみである

tailwindcssが使えるか確認するために、App.tsxに以下を追加する
function App() {
  return (
    <div className="App">
      <h1 className="text-3xl font-bold text-blue-500 underline">
        Hello world!
      </h1>
    </div>
  )
}

起動してもHello world!が表示されない場合は、tailwindcssの設定が正しくない可能性があるので、tailwind.config.jsとindex.cssを確認する

起動してHello world!が表示されるが、tailwindcssのスタイルが反映されない場合は、index.cssの@tailwindの記述が正しくない可能性があるので、index.cssを確認する
