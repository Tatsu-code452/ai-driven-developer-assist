# AI駆動型開発支援システム 開発スケジュール

## 全体方針

優先順位は以下の順で実施する。

1. AI作業削減効果が高いもの
2. 他機能の前提となる基盤
3. トレーサビリティ維持
4. GUI化
5. 周辺支援機能

想定期間

- Phase1 : 2週間
- Phase2 : 4週間
- Phase3 : 3週間
- Phase4 : 2週間
- Phase5 : 2週間
- Phase6 : 2週間
- Phase7 : 4週間

合計

約19週間
