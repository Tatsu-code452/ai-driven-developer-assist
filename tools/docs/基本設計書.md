# 管理データ変換機能 基本設計書

## 1. 概要

### 1.1 機能名称

管理データ変換機能

### 1.2 目的

Markdown成果物からプロジェクト管理データを生成する。

本機能は設計成果物とプロジェクト管理機能を接続する中核機能である。 

---

## 2. システム上の位置付け

設計成果物

↓

管理データ変換機能

↓

管理データ

├─ Task

├─ Document

├─ QA

├─ Issue

└─ Traceability

↓

プロジェクト管理

↓

ダッシュボード

本システムでは人間主体で作成した成果物を管理データへ変換し、開発状況の可視化を行う。
