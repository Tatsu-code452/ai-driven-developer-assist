## 採番管理ツール機能仕様書

### 文書ID

DES-004

### 機能ID

TSK-004

### 機能名称

採番管理ツール

---

### 1. 目的

AI駆動型開発支援システムにおいて利用する成果物識別子の発行・管理を行う。

本機能は以下を実現する。

- 一意な成果物ID発行
- 重複採番防止
- 並列開発時の採番競合防止
- トレーサビリティ維持
- AIによる自動成果物生成支援

成果物はトレーサビリティ管理の基盤となるため、全機能の前提となる基盤機能とする。 

---

---

### 3. IDフォーマット

#### 3.1 基本形式

```text
PREFIX-NNN
```

例

```text
REQ-001
DES-001
TSK-001
BUG-001
```

#### 3.2 採番規則

- PREFIXは大文字英字3文字
- ID部は3桁ゼロ埋め
- 001から採番
- 同一PREFIX内で重複禁止
- 欠番は許容

### 5. 機能仕様

#### SEQ-001 次ID取得

##### 概要

PREFIX単位で次の利用可能IDを取得する。

##### 入力

| 項目   | 必須 |
| ------ | ---- |
| prefix | ○    |

##### 出力

| 項目   | 内容         |
| ------ | ------------ |
| nextId | 次の採番候補 |

例

```json
{
  "nextId": "REQ-056"
}
```

---

#### SEQ-002 採番予約

##### 概要

並列作業に備えIDを予約する。

##### 入力

| 項目       | 必須 |
| ---------- | ---- |
| prefix     | ○    |
| branchName | ○    |
| ticketId   | ○    |

##### 処理

```text
REQ-056
状態 = RESERVED
```

登録

---

#### SEQ-003 採番確定

##### 概要

成果物作成時に予約IDを確定する。

##### 状態遷移

```text
RESERVED
 ↓
USED
```

---

#### SEQ-004 採番取消

##### 概要

使用しなかった予約番号を取消する。

##### 状態遷移

```text
RESERVED
 ↓
CANCELLED
```

---

#### SEQ-005 採番履歴参照

##### 概要

採番状況を一覧表示する。

##### 出力例

| ID      | 状態     |
| ------- | -------- |
| REQ-001 | USED     |
| REQ-002 | USED     |
| REQ-003 | RESERVED |

---

#### SEQ-006 重複チェック

##### 概要

成果物保存時にID重複を検査する。

##### エラー

```text
SEQ-DUPLICATE-ID
```

---

#### SEQ-007 ID再構築

##### 概要

管理データから採番状態を再生成する。

利用用途

- 障害復旧
- データ移行
- Git復元

---

#### SEQ-008 採番状態監視

##### 概要

異常採番を検知する。

監視対象

- 重複
- 形式不正
- PREFIX不正
- 予約放置

### 9. 並列開発対応

課題

```text
feature-a
feature-b
```

が同時に

```text
REQ-005
```

を採番すると衝突する。

要件

- 採番予約機能を使用する
- Gitブランチ情報保持
- Ticket情報保持
- 重複時はエラー



---

### 10. エラー一覧

| エラーコード     | 内容         |
| ---------------- | ------------ |
| SEQ-001          | PREFIX未指定 |
| SEQ-002          | 不正PREFIX   |
| SEQ-003          | 採番上限超過 |
| SEQ-004          | ID未存在     |
| SEQ-005          | 予約期限超過 |
| SEQ-DUPLICATE-ID | ID重複       |

### 11. 受入条件

#### AC-001

REQ-001採番後にREQ-002が採番される。

#### AC-002

異なるPREFIXは独立採番される。

```text
REQ-001
DES-001
TSK-001
```

#### AC-003

重複IDが登録できない。

#### AC-004

並列作業中でも重複しない。

#### AC-005

採番履歴が保持される。

#### AC-006

システム再起動後も採番状態が維持される。
