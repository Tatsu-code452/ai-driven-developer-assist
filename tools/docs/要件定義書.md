# 管理データ変換機能 要件定義書

## 1. 概要

### 1.1 機能名称

管理データ変換機能

### 1.2 目的

本機能は、要件定義書、設計書、WBS、議事録などの成果物から管理データを生成し、プロジェクト管理に利用可能な状態へ変換することを目的とする。

本機能により、

成果物作成

↓

管理データ生成

↓

進捗管理

↓

運用

を実現する。 

---

## 2. 背景

現在の開発では以下が存在する。

- 要件定義書
- 基本設計書
- WBS
- 成果物一覧
- 画面設計

一方で以下は未整備である。

- タスク管理データ
- QA管理データ
- 課題管理データ
- 進捗管理データ

本機能により成果物から管理データを自動生成し、プロジェクト管理機能を実現する。

## 5. 管理データモデル

### Task

| 項目            | 内容       |
| --------------- | ---------- |
| TaskId          | タスクID   |
| Title           | タイトル   |
| Description     | 説明       |
| Status          | 状態       |
| Priority        | 優先度     |
| Assignee        | 担当者     |
| RelatedDocument | 関連成果物 |

---

### QA

| 項目     | 内容     |
| -------- | -------- |
| QaId     | QA識別子 |
| Question | 質問     |
| Answer   | 回答     |
| Status   | 状態     |

---

### Issue

| 項目        | 内容   |
| ----------- | ------ |
| IssueId     | 課題ID |
| Title       | 課題   |
| Description | 内容   |
| Priority    | 優先度 |
| Status      | 状態   |

---

### Document

| 項目       | 内容     |
| ---------- | -------- |
| DocumentId | 成果物ID |
| Title      | タイトル |
| Type       | 種別     |
| Path       | 格納場所 |

## 6. 変換ルール

### MDR-001 見出し解析

Markdown見出しを解析する。

対象

- #
- ##
- ###
- ####

---

### MDR-002 タスク抽出

以下をタスク候補とする。

- TODO
- ToDo
- 作業
- 実装
- 対応
- 作成

---

### MDR-003 課題抽出

以下を課題候補とする。

- 課題
- Issue
- リスク
- 未対応

---

### MDR-004 QA抽出

以下をQA候補とする。

- QA
- 質問
- 確認事項

---

### MDR-005 採番付与

採番規則に従い自動採番する。

## 10. 非機能要件

### 性能

1000件以上の成果物を処理できること。

### 再現性

同一入力から同一結果を生成できること。

### 拡張性

新しい管理データ種別を追加できること。

### 可搬性

Markdown成果物から生成できること。 【1-787a1b】
