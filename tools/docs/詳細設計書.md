# 管理データ変換機能 詳細設計書

## 1. 概要

### 機能ID

CONV-001

### 機能名

管理データ変換機能

### 目的

Markdown成果物を解析し、プロジェクト管理で利用可能な管理データへ変換する。

対象

- Document
- Task
- QA
- Issue
- Traceability

本機能はプロジェクト管理機能の入口となる中核機能である。
