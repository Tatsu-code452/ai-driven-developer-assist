# WBS（AI開発オーケストレーションツール版）

## 前提

以下を前提とする。

- AIが成果物を生成する
- ユーザがローカルへ反映する
- 本システムは管理・可視化・AI投入を担当する
- GitHub Copilot無償版や他AIへの引継ぎを可能とする

本システムはコード生成ツールではなく
